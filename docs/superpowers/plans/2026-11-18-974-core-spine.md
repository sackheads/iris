> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `Principal` floor / `AccessProfile` grant / per-run `Binding` spine and close the C1–C8 fail-open seams, so every consumer (MCP, A2A, profile pane, cred registry, memory scoping) resolves one fail-closed model instead of inventing its own.

**Architecture:** A non-optional `Binding` (an `AccessProfile` capped by a `Principal` floor) is resolved from authenticated identity and stamped on the engine at the door, before the run starts. Enforcement moves to the data layer (tools + store consult the active binding), not prompt assembly. Non-owner bindings fail closed on every axis; the owner binding (`main`, or a run that inherits it) is the only unbounded one.

**Tech Stack:** Swift / SwiftUI, the existing `IrisKit` module; GRDB (`ConversationStore`); `SandboxPolicy`, `PermissionManager`, `ToolExecutor`, `IrisEngine` (`iris.swift`), `SubagentManager`, `GoalEvaluator`.

## Global Constraints

- **Fail closed on every non-owner axis (spec Inv 2, C8).** A missing binding, missing grant key, unmapped route, unclassified tool, or unreadable profile denies — never defaults to owner or host.
- **The axis is the BINDING, not the Principal (spec Inv 1).** A subagent on the owner binding is owner; a subagent dropped to a named profile is bound. Owner `main` (and runs inheriting it) keep ambient creds + the #966 git path — named exception (Brian 2026-11-15).
- **Identity is authenticated, never self-asserted (spec Inv 5, M4).** The profile is a property of the initiating authority, keyed `(transport, issuer, id)`, stamped before the engine runs; the task body can never name its own profile.
- **Policy is not model-writable (spec Inv 6, H3).** The `AccessProfile` store is written only by the #961 UI; no model-callable tool and no un-flagged host write reaches it.
- **AGENTS.md invariants:** Inv 1 (every new persisted `Codable` field uses `decodeIfPresent` or a `CodingKeys` exclusion); Inv 3 (per-tool-call state keyed by per-call UUID); Inv 7 (never mutate `ConfigManager.shared`/process-global state in tests — inject `ConfigManager(store:)`, `PermissionManager(paths:)`, scoped seams); Inv 9 (search for what a behavior change makes untrue — docs + agent-facing strings — and fix it).
- **Zero compiler warnings** in `Sources/`/`Tests/` (`scripts/check-warnings.sh`); fix at source, never suppress.
- **Tests:** Swift Testing (`@Suite`/`@Test`/`#expect`), not XCTest. Time elapsed bounds use `TestClock`, never `Date()`. Suites that start tasks/processes get `.timeLimit(.minutes(1))`. No `ConfigManager.shared` mutation.

## Review Focus

Input classes the spec implies that a task must pin (each gets its test in the owning task):

1. **A persisted `accessProfileId` that no longer names a live profile** (profile deleted/renamed after a conversation saved it) → must fail closed to refusal for non-main, not load as owner (Task 5 test).
2. **A subagent/evaluator spawned from a run that is itself non-owner** → the child's binding is `parent ∩ floor`, never widened back toward owner (Tasks 5, 10 tests).
3. **A no-widen drop whose target is narrower on four axes but wider on one** (e.g. same memory tier, one extra FS root) → refused, not accepted on majority (Task 4 test).
4. **A credential store reached by a symlink or a `..`-containing path under a non-owner binding** (e.g. `~/.config/gh` via a symlink) → denied; the FS-subset rule must resolve symlinks (Task 8 test; open decision below).
5. **A guest-steered `.main` turn on a role session** (the F3b path) → the recipient turn carries a non-owner binding, so its memory reads are tier-scoped even though the session is `.main` (Task 15 test).
